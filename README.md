# OpenGraft
An open-source implementation of the [Scion](https://www.anthropic.com/engineering/redesigning-source-control) source control architecture created by Anthropic. 
*(Named for the botanical practice of grafting a scion to create new growth.)*

## Name Disambiguation
This project is an independent implementation of the Scion architecture and is not affiliated with or in any way related to the existing [graft](https://github.com/odvcencio/graft) structural version control project.
